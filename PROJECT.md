# TextileRoute — current scope

Candidate question: can a measured NIR spectrum plus a dated, sourced recycler fibre-composition profile support useful accept/review/not-eligible decisions on an explicitly defined textile population? This is a local research prototype for GENIUS AI, not a purity certificate or novelty claim.

Status after B00: repository controls exist; dataset files, license, labels, independent grouping units, recycler criteria, baselines, calibration, performance, environmental effects and contest eligibility are **unverified**. No model has been trained. The prompt pack describes 71 physical samples, which is a starting source statement, not a verified evaluation sample count. Synthetic B00 fixtures test control behavior only.

The next decision gate is B01 rules and problem definition. Scientific scope and claims may narrow after data and prior-art audits. Outputs must distinguish surface NIR evidence from unobserved layers, finishes, trims, moisture and process conditions. Public claims will require the verified result ledger; drafts and release remain separate.
