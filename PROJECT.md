# TextileRoute — current scope after B03

The verified small OpenTextile-NIR v1.0 release supports a **grouped exploratory dataset audit and prospective reproduction study**, not a validated recycler decision system. The current question (H02-2) is whether classical NIR composition modeling can be transparently reproduced on the supplier-labelled pieces and how specimen grouping, unknown labels and whole-dataset outlier selection limit interpretation. No new estimator or formal method has been identified. No model has been trained or performance result produced.

The Zenodo record and CC BY 4.0 license were verified; six small files matched published hashes. Actual tables contain 71 physical pieces, 70 conservative parent-prefix groups, 57 unflagged nominal compositions, 11 model-derived outlier flags and 3 unknown compositions. The unflagged 2024 JRC composition scenarios have only 6 nominal ≥80% cotton and 10 nominal ≥95% polyester positives. These counts are insufficient for the proposed confirmatory selective false-acceptance claim. Supplier composition is not a chemical assay, NIR measures a surface region, and neither the historical JRC thresholds nor Infinited's approximate preference establish complete or current industrial acceptance. Full findings and unsupported cases are in `protocol/data_audit.md` and `research/decisions/ADR-003-data-gate.md`.

NIST NIR-SORT 2.0 is a stronger potential alternative on provenance and instrument coverage, but the specimen-level source files could not be retrieved from the official file endpoint in B03, so its threshold feasibility is unknown. HyperTex files are embargoed through 2026-09-30. Reopen the data decision when stronger files and labels can be audited; do not merge different instruments without an explicit protocol. The current request prohibits tests, so only the read-only data inventory and source/structure checks have been performed. All public result claims require a verified result ledger. Submission and authentic student work remain separate release gates; `submission_ready=false`.
