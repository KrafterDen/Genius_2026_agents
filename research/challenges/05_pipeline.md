# B05 independent pipeline challenge — 2026-09-25

Requested read-only Luna Xhigh challenge; no worker edits, executions or tests. Exact runtime model identity was not exposed. The challenger compared the supplied mean SWIR table, cube/pixel expansion and RGB fusion against the frozen B04 question, and compared stdlib parsing with heavier array-cache formats. Root adopted the following source- and contract-based outcome before fitting any model.

The [authors' article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12925456/) and B03 inventory make the 71 piece-level means the aligned input for B04. A cube offers spatial detail but pixels from one piece share its supplier label and source dependence. Treating them as independent training or evaluation items would inflate the apparent sample count. The RGB table describes a different ROI and is not evidence of fibre chemistry; it stays joinable context. Mean spectra cannot establish within-piece heterogeneity or whole-garment purity. The larger cube was therefore not fetched for B05. A future spatial task needs a new outcome and group protocol.

For four small semicolon CSVs, Python's [CSV parser](https://docs.python.org/3/library/csv.html), JSON and hashing have fewer serialization assumptions than an added persistent NumPy cache. NumPy remains useful later for estimator matrices, and [NumPy's own loading guidance](https://numpy.org/doc/stable/reference/generated/numpy.load.html) supports avoiding pickle-backed input. The output is plain canonical JSON/JSONL with source hashes. [SciPy's Savitzky–Golay definition](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html) anchors the optional transform's window, polynomial and edge behavior. Learned scaling and estimators must be fit inside B04's groups; [scikit-learn Pipeline](https://scikit-learn.org/stable/modules/generated/sklearn.pipeline.Pipeline.html) is the candidate later integration boundary, but no model pipeline was fit or validated here.

The challenger independently flagged the source residual marker as whole-dataset-model-derived and the unknown marker as nondeployable. They are metadata, never columns of the spectral feature vector. The B04 exact group map is retained rather than asking [GroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html) to make a different allocation. Source file sizes, hashes, exact IDs, full grid and units are pinned; the asserted nanometre/fractional-reflectance convention is stated explicitly because the CSV does not print units.

Static review supports the architecture but cannot establish that the command reconstructs data, catches deliberate leakage violations, or fits machine memory. Those are B05 acceptance gates and remain unmet because the current user/root AGENTS.md prohibit all test and smoke execution.
