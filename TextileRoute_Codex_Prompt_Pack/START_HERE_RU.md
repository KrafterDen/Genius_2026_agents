# TextileRoute — пакет для локального Codex

Это **промпты и управляющие шаблоны**, а не уже выполненное исследование. Промпты — на английском; итоговый отчёт планируется на украинском, международная версия — на английском.

## Запуск
1. Распакуй **всю папку** в корень нового рабочего проекта, оставив имя `TextileRoute_Codex_Prompt_Pack`. Открой родительскую папку в Codex. Выбери **GPT-6 Sol / High**.
2. Вставь целиком `prompts/00_BOOTSTRAP.md`. Он создаёт репозиторий, AGENTS.md, состояние проекта, проверяет инструменты и доступные модели. Существующие файлы он не должен затирать.
3. Затем вставь `prompts/AUTOPILOT.md`: агент последовательно выполняет блоки 01–19 и сохраняет состояние. Альтернатива — давать файлы 01–19 по порядку вручную.
4. После остановки или нового чата используй `prompts/RESUME.md`. Он продолжает с файлов на диске, а не полагается на память разговора.

Для серии отдельных CLI-сессий есть **необязательный** `tools/run_blocks.py`. По умолчанию он только показывает план. Реальное исполнение требует `--execute` и конфигурации, которую блок 00 проверил именно для установленного Codex. Команда описана в `tools/README.md`. Сам агент не должен запускать этот runner внутри собственной сессии.

## Что где
| Путь | Назначение |
|---|---|
| `prompts/00…19` | 20 крупных рабочих блоков: исследование → данные → ML → проверка → демонстрация → материалы конкурса. |
| `framework/` | Правила делегирования, научной проверки, веб-поиска, ограничений и полного комплекта подачи. |
| `repository_template/` | Начальные AGENTS.md, JSON-шаблоны, журналы, схемы и примеры конфигурации субагентов. |
| `sources/` | Проверенные исходные источники, снимок правил и явно неразрешённые вопросы. |
| `tools/` | Проверка целостности пакета и необязательный последовательный CLI-runner. |

## Важные границы
Каждый блок рассчитан на **180–240 минут содержательной работы**, с дополнительными проверками при быстром завершении основного объёма. Это план нагрузки, не гарантия длительности: агент не должен искусственно ждать три часа, имитировать работу или скрывать раннее завершение.

Маршрутизация: Sol High — оркестратор; Luna Xhigh — простые ограниченные задачи; Sol Medium — сложные; Astra High — точечный разбор самых трудных научных рисков. Блок 00 проверяет доступность моделей и фактический синтаксис клиента. Платные облачные вычисления и новые API-покупки по умолчанию запрещены.

План минимизирует рутину, но **не подменяет реальный вклад участника**. Личные данные, настоящая самостоятельная часть исследования, собственная защита, согласия и окончательная отправка остаются за тобой. Видео требует английской озвучки; собственный голос предложен как основной вариант, но не выдан за отдельно подтверждённое правило. Агент подготовит материалы, инструкции и один сводный список необходимых действий; он не будет выдумывать твой вклад или выдавать свою работу за твою.

Правила Украины на сезон 2027 ещё могут меняться. Встроены перепроверки. Датасет содержит только 71 физический образец: пригодность меток для пороговой сортировки и возможность заявлений о риске сначала проверяются, а не предполагаются.
