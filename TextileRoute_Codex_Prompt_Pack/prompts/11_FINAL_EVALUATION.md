Execute the predefined experiment, not an adaptive search for a winning number. Produce a verified ledger of what the data actually supports.

## Work sequence

### Integrity and execution — 55–70 min
Check frozen hashes and independent groups. Execute the run matrix with one heavy job at a time, logging every run and exact test access. Resume incomplete jobs only when manifests match. Do not modify a model after viewing held-out outcomes. Distinguish training failures, insufficient calibration and zero-acceptance from valid scores.

### Primary analysis — 50–65 min
Calculate preregistered metrics, paired comparisons and uncertainty at the independent-unit level. Report item counts alongside every percentage, selected-set denominators, review budget and eligible/ineligible distribution. Show simple baseline, existing risk control, custom method and ablations. Preserve wide intervals and inconclusive results.

### Independent recomputation — 40–55 min
Recompute key values from raw prediction tables in an independent path. Check no threshold was selected using final outcomes, no repeated-fold count inflated n, and no skipped difficult cases were hidden. Verify plots match CSVs. Do not create an attractive significance story unsupported by the protocol.

### Verified result ledger — 35–50 min
Write machine-readable final summaries with run IDs, inputs, uncertainty, denominators and allowed wording. Mark each primary hypothesis supported/unsupported/inconclusive under the actual evidence. Save all failures. Create a concise findings report and update claims. Any discovered issue triggers documented invalidation, not silent rewriting.

## Independent web challenge
The independent reviewer should attempt to reproduce the headline using only saved predictions and documented formulas. Search externally only for a material statistical question, not for post-hoc methods that make results significant.

## Acceptance gates
1. Final runs obey the freeze and all attempted outcomes are preserved.
2. Metrics reproduce from stored predictions with independent denominators.
3. No false guarantee or post-hoc winner selection occurs.
4. Ledger states actual positive/negative/inconclusive findings and exact evidence.

## Meaningful depth work after the core
Check deterministic reruns where affordable, audit per-group denominators and validate plot exports and failure manifests. Do not spend extra time retuning.

## Stop, narrow or invalidate when necessary
On a critical implementation error, explicitly mark affected results invalid, version the fix and record the compromised test status. A new confirmatory claim may require new untouched data.
