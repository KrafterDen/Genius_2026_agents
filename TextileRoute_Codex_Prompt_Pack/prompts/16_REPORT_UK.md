## Work sequence

### Rule refresh and outline — 35–45 min
Reopen current Ukraine 2027 AI and participant pages plus any newly published template. Resolve page/size/language rules with exact source evidence. Plan title, problem/context, related work and gap, question, data, method, experiments, results, cost/environment, limitations, conclusion, contributions and references. User requested Ukrainian. Missing personal information stays private/placeheld and draft-only.

### Evidence-backed writing — 65–80 min
Write fluent Ukrainian explaining the project to a technically literate judge. Pull every number from verified_summary/claim ledger and identify actual denominators/uncertainty. Describe supplier labels, small sample size, existing methods, failed hypotheses, non-certification and contribution scope accurately. Cite actual primary sources near claims. Do not make negative findings sound positive through vague wording. Personal-work statements must match the real log.

### Document build — 45–60 min
Create a reproducible DOCX/PDF build process using an inspected, justified toolchain. Current baseline: Arial/Calibri11/12, 2.5cm margins, <=15 pages including appendices but excluding title/references, PDF <=5MB. Prefer a layout with safe margin below limits. Use real result figures with captions and source/tool attribution. Do not distribute fonts or invent figures. Generate editable source plus DOCX and PDF.

### Render and audit — 40–55 min
Render every PDF page and inspect Cyrillic glyphs, clipping, headings, tables, figures and page breaks. Verify DOCX/PDF semantic agreement, byte size, body page count, citations and no unfinished scientific placeholders. Independent review checks claim strength and exact wording. Record unresolved eligibility/contribution fields as release blockers, not a false compliant-final status.

## Independent web challenge

## Acceptance gates
1. Ukrainian report is complete on scientific content and uses only verified results.
2. Current national formatting/page/size requirements are checked against rendered files.
3. Sources support claims, and original/AI/student contributions are not fabricated.
4. All pages are visually inspected; any remaining personal/release items are explicit.

## Meaningful depth work after the core
Test automatic metric-to-text consistency, cross-reference integrity, accessible figure captions and a smaller-file-size render without unreadable plots.

## Stop, narrow or invalidate when necessary
If current rules cannot be confirmed, provide clearly labelled working-baseline drafts. If authentic personal contributions are pending, retain DRAFT status rather than inventing them.
