## Work sequence

### Final rule and claim refresh — 40–55 min
Recheck applicable organizer rules and unresolved questions immediately before preparing release. Verify every required file/language/page/size/video/contribution item against the exact category and season. If changed, rebuild only affected artifacts and rerun validation. Check claims against measured evidence and close or expose critical audit findings.

### Clean-room and artifact verification — 55–70 min
Reproduce the documented smoke flow, key metric recomputation, offline demo and reports from packaged inputs. Check citations, licenses, private-data exclusion, model safety, versions, hashes and consistency across English/Ukrainian text/slides/video. Distinguish publicly distributable code/fixtures from private personal forms and restricted raw data.

### Package by stage — 45–60 min
Build national, international-ready and supporting local directories/archives with a manifest including destination, validator, source rule, checksum and status. Draft actual application text and tested publication instructions but leave live links pending until user approval. Never invent submission IDs or organizer responses. Include a reproducibility index and a final limitations/novelty statement.

### Human handoff and project closure — 40–55 min
Create one short Russian handoff showing what exists, where it is, how to reproduce, and only the remaining indispensable human actions. State actual student contribution, narration, eligibility and publication status. Set submission_ready true only when all applicable validated and human gates really pass; otherwise output needs_human/blocked with exact reasons. Archive actual run/agent logs and next actions, preserving no secrets.
