# Execution order

Run **00 once**, then **AUTOPILOT**, or feed **01 through19** one by one. Use **RESUME** in a fresh context. Research can alter an approach, not silently skip data/validity gates. Each block is a substantial 180–240-minute planning package; a 20-block nominal baseline is 60 productive hours, not a runtime promise.

| Block | Purpose |
|---|---|
| 00 | Initialize the repository and a recoverable autonomous workflow |
| 01 | Verify the industrial problem and current competition requirements |
| 02 | Find the closest prior art and narrow the contribution |
| 03 | Retrieve small data first and decide whether the target is identifiable |
| 04 | Preregister the experiment and validate what can be claimed |
| 05 | Implement audited data ingestion, preprocessing and leakage guards |
| 06 | Establish strong low-compute baselines and honest learning curves |
| 07 | Implement uncertainty and selective decisions without false guarantees |
| 08 | Choose one defensible custom contribution using falsification pilots |
| 09 | Implement the selected method, fair review workflow and ablations |
| 10 | Freeze the protocol, code and final experiment matrix |
| 11 | Run the frozen evaluation and preserve all outcomes |
| 12 | Evaluate preregistered robustness and delimit generalization |
| 13 | Quantify the measured value and separate it from hypothetical benefits |
| 14 | Build a clear, offline demonstration using the actual trained pipeline |
| 15 | Reproduce the whole project and prepare authentic student understanding |
| 16 | Write and render the Ukrainian national research report |
| 17 | Prepare the international English paper and synchronized supporting documents |
| 18 | Produce the demonstration, presentation, narration package and defense kit |
| 19 | Validate the complete submission package and produce a truthful handoff |

The optional CLI runner starts a fresh process per block and requires explicit execution authorization. It stops at failed/blocked evidence gates. Later human release actions do not prevent drafting, but cannot be silently marked complete.
