# TextileRoute B04 preregistered exploratory protocol — draft freeze

**Dated 2026-09-25. Status:** methodological plan only. No model has been fit, no performance result has been observed, and the current request does not authorize creating or running tests. This protocol is frozen for any later authorized analysis at the SHA-256 recorded in the B04 block report. Changes after that point require an amendment log and cannot silently replace this primary analysis. It is an internal preregistration, not a human signature or a registered external study.

## Question and population

Primary H02-2 question: **On a previously unseen conservative parent-prefix group from the same OpenTextile collection, how accurately can a classical SWIR pipeline estimate the dataset authors' nominal cotton + wool + lyocell percentage compared with a training-only constant predictor?** The name “natural-fibre share” is used only as shorthand for this exact author-defined sum; lyocell is included because the [source's example analysis](https://pmc.ncbi.nlm.nih.gov/articles/PMC12925456/) includes it. This is supplier-reported composition, not a present-day chemical assay or verified recycler eligibility.

Input is one provided 288-band mean SWIR reflectance spectrum per cut piece, from 953.04 to 2547.64 nm. Seventy-one pieces have spectra. Sixty-eight have nominal fibre shares summing to 100; these form 67 conservative parent groups. The three explicitly unknown compositions have no supervised target. Eleven of the 68 known rows carry source outlier flags produced by whole-dataset spectral-model residuals. They remain in the primary population; a report on the 57 unflagged rows is only a secondary sensitivity analysis. The parent group is the numeric prefix before the first hyphen; both `sample_45` pieces remain together. Unknown extra dependence by supplier, garment lot or scan session remains a limitation. Neither ROI pixels nor bands are independent pieces. `protocol/data_audit.md` and `protocol/grouping.json` are the frozen data inventory.

The descriptive routing context is the historical 2024 JRC ≥80% cotton and ≥95% polyester *composition-only* proxies. They are not current universal contracts or whole-item acceptance requirements. RGB values, trims, backing layers, finishes, moisture, reuse triage, contamination and item masses are outside the measured target. In a future hypothetical route display, `ACCEPT` means automatic acceptance for a named composition proxy, `REVIEW` defers to a human with unmeasured accuracy, and `DECLINE` means automatic nonacceptance for that proxy, not waste disposal. No output may claim an actual recycler will accept the garment. The approximate Infinited 88% cotton preference remains context, not an exact binary target.

## Primary estimand and competitors

The primary endpoint is **parent-group-equal mean absolute error in percentage points** for the author-defined nominal sum. Each group contributes the mean of its piece-level absolute errors, then the 67 group means are averaged. Predictions are clipped to [0, 100] by a prespecified rule. The single primary comparison is `MAE_constant − MAE_PLS` on identical outer held-out groups; positive values favor PLS. A within-collection paired group resampling interval, if later calculated, is descriptive and cannot certify general textile performance. `protocol/metrics.json` gives precise formulas and denominators.

Competitors are fixed before any fitting:

1. **No-spectrum baseline:** constant group-weighted median of the nominal target among each outer-training set, with each parent group assigned equal total weight and ties resolved to the lower median; never calculated using the held-out group. This is the serious simple comparator for MAE.
2. **Source-informed classical PLS:** convert positive reflectance to absorbance with `−log10(max(R, 10⁻⁶))`; Savitzky–Golay polynomial degree 2, window 9; retain fixed source-reported 1411–2536 nm wavelengths; apply per-piece standard normal variate; fit PLS regression. Select only components 1–10 using inner grouped MAE. All learned centering/scaling and PLS coefficients fit inside training boundaries. The preprocessing choices follow the [article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12925456/); logarithm base and numerical floor are explicit implementation conventions requiring a discrepancy note if source code later reveals a different convention.
3. **Modest regularized linear alternative:** same fixed spectral transforms, Ridge with alpha grid `{0.1, 1, 10, 100}` after training-fold feature standardization. Select alpha by the same inner grouped MAE; break ties toward larger alpha. This is secondary, not a new method claim.

The source paper's four-component PLS and its published **5.18 percentage-point RMSE** may be described as prior work, but never treated as a like-for-like target or beaten-result: the paper omitted its 11 residual-flagged samples and three unknown rows, chose complexity on that collection and used a different evaluation population. An optional fixed-four-component reproduction is diagnostic only and is visibly labeled source-informed. No neural model, architecture search, RGB fusion, pixel expansion or external dataset pooling is authorized by this plan.

## Internal grouping, tuning and access boundaries

`protocol/split_plan.json` fixes one deterministic five-fold allocation of all 70 parent-prefix IDs by SHA-256 of a constant seed string and round-robin assignment. Three unknown-label groups remain on the map but do not contribute to supervised fitting or scoring. For each outer fold, a four-fold group-disjoint inner allocation on the labeled outer-training groups selects only the prespecified PLS component count or Ridge alpha. Train-only operations include any fitted centering, scaling, imputation, feature choice, parameter fit or decision-margin choice. Each known piece receives exactly one outer-held-out prediction; two pieces in a parent group are held out together. The five fold results are pooled at the group-loss level, not counted as five independent studies.

A disjoint train/tune/calibration/final allocation was considered and rejected for this dataset. It would leave very few of the 6 unflagged cotton or 10 unflagged polyester nominal positives in each partition; all composition labels were already inspected for B03 feasibility. Therefore there is **no dedicated sealed final test** and no confirmatory performance estimate in the current collection. The outer folds are internal exploratory evaluation, even though each group is unseen by its fold's fit. A formal calibrated binary selective-risk rule is not attempted. Any later independent NIST/HyperTex or newly collected source requires its own access, license, grouping and label audit plus a newly frozen protocol before a confirmatory claim. The current `protocol/test_access_log.jsonl` records exactly what data were inspected.

## Secondary descriptions, uncertainty and interpretation

Predeclared secondary outputs, only if later authorized, are group-equal RMSE for the author-defined sum; group-equal MAE for nominal polyester and cotton percentage; MAE stratified by the source outlier flag without changing the primary training population; a clearly labeled 57-row source-compatible analysis; and descriptive counts at the two historical composition proxy thresholds. For a strictly descriptive composition-proxy action illustration, fit separate cotton and polyester PLS regressions with the same inner component grid, then use two **fixed** margins of 0 and 2 percentage points: ACCEPT when clipped predicted fibre share is at least threshold plus margin; DECLINE when it is below threshold minus margin; REVIEW otherwise. The review-all zero-coverage reference is reported. No margin is chosen from outer results, no feasible operator review budget has been established, and no result is a full recycler acceptance decision. A direct classifier or calibrated risk controller is deferred with H02-1 because its positive-group capacity is inadequate. Do not promote a winner chosen from outer results to a separately validated system.

When action outputs are available, report raw counts and denominators: false accepts divided by accepted evaluable items; automatic acceptance coverage divided by evaluable items; review count and rate, including a separately stated all-71 denominator; automatic false declines among eligible items; and eligible items not automatically accepted. The three unknown-composition rows are unscored and shown as unresolved/REVIEW by the evaluation policy solely because the released metadata flags them; this is not spectral unknown detection or a deployable input feature. If no items are accepted, accepted-set risk/precision is **undefined** and coverage is zero; reject-all is not a success. Unknown-composition items never become true negatives. Supplier labels are a proxy reference, and a perfect-review policy is merely an explicitly hypothetical oracle simulation. Item-count metrics do not establish stream-mass purity; mass and verified material fractions would be needed.

Uncertainty, if later computed, is the paired 10,000-draw parent-group resampling interval for the primary loss difference, seeded `20260925`, and raw error distributions. It is exploratory: outer models share training items, source groups may share hidden supplier batches, and supplier labels may be wrong. Repeated folds or resampling never create more independent garments. For hypothetical accepted-label errors, report the interval specified in `protocol/metrics.json` for stated `k=1,2,3` only as a sensitivity calculation; no credible upper bound on supplier mislabels has been established. At an exact reported threshold, such as 80% cotton, mark boundary uncertainty rather than declaring chemical eligibility.

## Decision and negative-result rule

The registered main display will show all three models' group-equal MAE, the paired constant-minus-PLS contrast, a descriptive interval, and every source flag stratum. If PLS does not lower MAE versus the constant predictor, report a negative result. If the point difference favors PLS but the descriptive interval includes both benefit and harm, report an inconclusive result. If the interval favors PLS, describe only a within-collection exploratory improvement against supplier labels, without a formal population guarantee or new-method claim. Ridge outperforming PLS is reported, not hidden. If labels or grouped predictions are unusable, publish the audit limitation. No review/threshold result may override the primary endpoint after the fact.

All model families, transforms, component/alpha grids, group assignment, metric definitions, treatment of flags/unknowns and result labels are fixed here. Later deviations, failures, missing outputs and resource use belong in an append-only run ledger with source revision, environment, seed and reason. Any change after outer predictions are seen is exploratory; confirmation requires new independent evidence. No final result, emissions reduction, industrial trial or student contribution is implied by this plan.
